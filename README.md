# Manukora AgentOS for Paseo

Sets up Manukora AgentOS on your Mac or Windows PC and keeps it up to date. For Manukora staff. Windows support is new (beta): if a step fails, use the report box on the setup screen.

1. Install [Paseo](https://paseo.sh).
2. In Paseo, open **Settings → Plugins**, turn on **Enable plugins**, paste `git:manukora-nz/agentos-paseo-plugin` into **Plugin source**, and select **Install plugin**.
3. Open **AgentOS setup** in the sidebar, press **Connect**, and sign in with your Manukora Google account. The screen walks you through the rest.

This plugin holds no company content, keys or passwords. AgentOS itself is downloaded from Manukora's service after you sign in. Problems or ideas: use the **Something wrong, or an idea?** box on the setup screen.
